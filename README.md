## 📌 Project Overview

This project presents an **end-to-end Exploratory Data Analysis (EDA)** of an e-commerce dataset using **Python, Pandas, and Plotly**.  
The goal is to analyze **sales performance, profit trends, customer segments, and product behavior** through **interactive visualizations**.

The project simulates a **real-world business analytics workflow** and demonstrates practical data analyst skills.

---

## 🎯 Objectives

- Analyze **sales and profit** across customer segments  
- Identify **top-performing** and **loss-making** product categories  
- Understand **monthly sales and profit trends**  
- Support **data-driven business decisions** using insights  

---

## 🧰 Tools & Technologies

| Tool | Purpose |
|-----|--------|
| **Python** | Core programming language |
| **Pandas** | Data cleaning and manipulation |
| **Plotly (Express & Graph Objects)** | Interactive visualizations |
| **Jupyter Notebook** | Analysis and reporting environment |

---

## 📊 Analysis Performed

- Sales and profit analysis by **customer segment**
- Profit contribution by **category and sub-category**
- Identification of **high-profit and loss-making products**
- Monthly **profit trend analysis**
- Comparative analysis of **sales vs profit**

> All visualizations are **interactive**, enabling hover-based insights, zooming, and better data exploration.
